SingularIntegrals.jl

A Julia package for computing singular integrals involving Hilbert/Stieltjes/Cauchy, log, and power law kernels.

Examples

Expand $\exp(x)$ in Legendre polynomials and compute singular integrals against it:

julia> using SingularIntegrals, ClassicalOrthogonalPolynomials
julia> P = Legendre(); x = axes(P, 1); f = expand(P, exp);
julia> inv.(10 .- x') * f # Stieltjes: ∫₋₁¹ exp(x) / (10-x) dx0.24332755428373515
julia> inv.(0.1+0im .- x') * f - inv.(0.1-0im .- x') * f ≈ -2π*im*exp(0.1) # example of Plemeljtrue

Power law kernels are supported for Legendre and weighted ultraspherical bases:

julia> (abs.(10 .- x') .^ 0.2 * Legendre())[1:5] # ∫₋₁¹ (10-x)^0.2 * P_k(x) dx for k = 0,…,45-element Vector{Float64}:
  3.1689389691547674
 -0.021162455415691145
 -0.00033933394993157853
 -8.74599143396353e-6
 -2.727481731934075e-7

Log kernels are supported for weighted bases:

julia> W = Weighted(ChebyshevU()); f = expand(W, x -> exp(x) * sqrt(1-x^2));
julia> log.(abs.(10 .- x')) * f # Log-kernel: ∫₋₁¹ log(10-x) * exp(x) * sqrt(1-x^2) dx4.043032838853287
julia> log.(abs.(0.3 .- x')) * f # ∫₋₁¹ log(abs(0.3-x)) * exp(x) * sqrt(1-x^2) dx-2.3203915590084447

API

SingularIntegrals.AssociatedWeight — Type
AssociatedWeighted(P)

We normalise so that orthogonalityweight(::Associated) is a probability measure.

source
SingularIntegrals.cauchy — Method
cauchy(P, z)

computes inv.(t'-z) * P/(2π*im) where t = axes(P,1).

source
SingularIntegrals.complexlogkernel — Method
complexlogkernel(P)

applies the log kernel log(x-t) to the columns of a quasi matrix, i.e., (log.(x - x') * P)

source
SingularIntegrals.hilbert — Method
hilbert(P, x)

computes inv.(x - t') * P/π in a principle value sense where t = axes(P,1) and x in t.

source
SingularIntegrals.hilbert — Method
hilbert(P)

computes (inv.(x - x') * P)/π understood in a principle value sense.

source
SingularIntegrals.logkernel — Method
logkernel(P)

applies the log kernel log(abs(x-t)) to the columns of a quasi matrix, i.e., (log.(abs.(x - x')) * P)

source
SingularIntegrals.stieltjes — Method
stieltjes(P, z)

computes inv.(z - t') * P where t = axes(P,1).
